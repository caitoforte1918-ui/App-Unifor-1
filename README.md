Este projeto tem como objetivo o desenvolvimento de um sistema que simule um aplicativo de biblioteca online da Universidade de Fortaleza (Unifor). A proposta visa criar uma solução digital que possa otimizar e modernizar a experiência dos usuários da biblioteca, facilitando o acesso à leitura de caráter educativo informativo, de lazer, e de outros recursos que aprimorem a interação entre alunos e o espaço literário da instituição.

O principal objetivo deste trabalho é criar um sistema funcional e interativo para a biblioteca da Unifor, utilizando a linguagem de programação Kotlin e o IDE Android Studio como principais ferramentas de desenvolvimento. O aplicativo buscará oferecer uma interface intuitiva e recursos que poderão contribuir para a gestão e organização da leitura, proporcionando uma experiência mais eficiente e marcante aos usuários. Além disso, pretende-se garantir que o sistema atenda aos princípios de usabilidade, desempenho e boas práticas de desenvolvimento mobile.


Principais Ações no Sistema:
 *Estudante/Aluno:
	- Visualizar catálogo de livros
	- Ler Livro
	- Avaliar livro e ver semelhantes
	- Gerenciar perfil e foto
	- Interagir com chatbot
	-shor notificações
	- Acessar jogos físicos
	- Solicitar aluguel de livro
 *Administrador:
	- Gerenciar perímetro de livros
	- Gerenciar acervo de jogos físicos
	- Gerenciar alunos
	- Aprovar/Recusar cláusulas de aluguel
	- Monitorar livros lidos pelo aluno
	- Visualizar registros
